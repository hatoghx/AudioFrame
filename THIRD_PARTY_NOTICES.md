AudioFrame itself is licensed under the MIT License (see `LICENSE`).

The distributed Windows release binary (`x86_64-pc-windows-msvc`) statically
links the third-party crates listed below. Each is redistributed under the
license(s) shown next to it. Build-only and dev-only dependencies are not
redistributed and are excluded.

This file is generated mechanically:

```
powershell -ExecutionPolicy Bypass -File tools/gen-third-party-notices.ps1
```

Do not edit it by hand. The dependency set is pinned by `Cargo.lock`; the
accepted-license allow-list is in `about.toml`. `cargo about` fails if any
dependency introduces a license outside that list. The script additionally
splices in `fonts/UFL.txt` (Ubuntu Font Licence 1.0) from the
`epaint_default_fonts` source package, which `cargo about` cannot resolve on
its own.
